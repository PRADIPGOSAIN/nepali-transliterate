नेपाली Transliterate

Two independent offline modes. Romanized: type namaste kasto chha → नमस्ते कस्तो छ. Traditional: type with Nepali-keyboard habit (k→प, f→ा). Based on ne-rom-translit.

— see every key, click to type, or press your real keys and watch them light up.
  1. Home row: left hand a s d f → ब क म ा, right hand j k l ; → व प ि स. Drills (Traditional mode): n f d → लाम, k d → पम, h f g f d → जानाम. Repeat until automatic.
  2. Vowels: f→ा l→ि '→ु "→ू ]→े c→अ A→आ.
  3. Shift layer: capitals give compounds — Q→त्त T→ट्ट I→क्ष !→ज्ञ $→द्ध.
  4. Conjuncts: \ is halant ् — k \ q → क्त. [ is repha र्.
  5. Words: gfdLGL → नामीद्दी. Graduate to Romanized mode: namaste → नमस्ते.
Tips (Romanized): long vowels — double them (aa→आ, ii→ई, uu→ऊ). Retroflex — capitals (T→ट, D→ड, or t/→ट). Compounds: ksh→क्ष, tr→त्र, gyn/jn→ज्ञ. Full stop: .→। Numbers 0-9 → ०-९. Traditional mode: keys map directly — home row a s d f g h j k l → ब क म ा न ज व प ि.
